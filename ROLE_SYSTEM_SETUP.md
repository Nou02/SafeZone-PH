# Role System Setup Guide

## Overview
The app now has a hierarchical role system:
1. **City Admin** (`illinoispss@gmail.com`) - Can manage barangays and generate Head Official passcodes
2. **Head Barangay Official** - Can generate passcodes for regular Barangay Officials
3. **Barangay Official** - Regular verified users

## Database Setup

Run the SQL in `supabase_role_system.sql` in your Supabase SQL Editor. This will create:
- `barangays` table - Stores barangays with unique Head Official passcodes
- `barangay_official_passcodes` table - Stores passcodes generated by Head Officials
- RLS policies for security

**Important**: The SQL file has been fixed to use `auth.jwt()` instead of querying `auth.users` directly.

## How It Works

### City Admin Flow:
1. Login as `illinoispss@gmail.com`
2. Go to Profile → "Manage Barangays"
3. Add a barangay (system generates a unique passcode)
4. Share the passcode with the Head Barangay Official

### Head Barangay Official Flow:
1. User enters the Head Official passcode in Profile → "Barangay Official Verification"
2. User becomes a Head Barangay Official
3. Go to Profile → "Generate Passcodes"
4. Generate passcodes for Barangay Officials
5. Share passcodes with regular users

### Barangay Official Flow:
1. User enters a Barangay Official passcode in Profile → "Barangay Official Verification"
2. User becomes a Barangay Official
3. Passcode is marked as used (one-time use)

## Features

- **Unique passcodes** for each barangay (Head Official level)
- **One-time use passcodes** for Barangay Officials
- **Role-based UI** - Different options shown based on user role
- **Secure RLS policies** - Users can only access data for their barangay

## Notes

- Passcodes are case-insensitive (automatically converted to uppercase)
- Barangay Official passcodes can optionally have expiration dates
- Once a passcode is used, it cannot be reused
